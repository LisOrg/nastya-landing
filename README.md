# nastya-landing

Лендинг-визитка Анастасии Лисовенко (психология + преподавание химии).

## Локальный запуск

Вариант 1 (Python 3):

```bash
python -m http.server 8080
```

Открыть: [http://localhost:8080](http://localhost:8080)

Вариант 2 (Node.js, без установки глобально):

```bash
npx serve .
```

## Деплой на Netlify

Проект статический, сборка не требуется.

Способы:

1. Подключить репозиторий в Netlify и выбрать корень проекта.
2. Или перетащить папку проекта в Netlify Drop.

`netlify.toml` уже добавлен, `publish = "."`.
